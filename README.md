## Overview

**MediCare** is a Hospital Management System (HMS) frontend that lets patients browse hospital services and book appointments online, while giving staff a simple set of pages to log in and manage patient records and profiles.

Built entirely with **HTML and CSS** — no backend, no framework, no dependencies.

## Key Features

### Patient-Facing Pages

| Page | Description |
|---|---|
| **Home** (`index.html`) | Landing page introducing the hospital and its services |
| **Doctor Directory** (`doctors.html`) | Browse doctors by specialty, qualification, and experience |
| **Appointments** (`appointments.html`) | Book consultations with doctors online |

### Account & Records Pages

| Page | Description |
|---|---|
| **Login** (`login.html`) | Authentication gateway for registered users |
| **Profile** (`profile.html`) | View and manage personal account details |
| **Patients** (`patients.html`) | Registry view of patient records |

## Getting Started

The project is a static frontend, so no build tools or servers are required.

```bash
# 1. Clone the repository
git clone https://github.com/ajaypratap9/Hospital-and-Healthcare-Management-System.git

# 2. Move into the project folder
cd Hospital-and-Healthcare-Management-System

# 3. Open index.html in your browser
#    (or use the "Live Server" extension in VS Code for hot-reload)
```
